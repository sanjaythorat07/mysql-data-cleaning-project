# MySQL Data Cleaning Project

## 📌 Project Overview
This project demonstrates data cleaning using MySQL, including:
- Removing duplicates
- Handling NULL values
- Standardizing data formats
- Fixing inconsistent text values
- Applying constraints

## 🛠 Tools Used
- MySQL
- MySQL Workbench
- CSV Dataset
- GitHub

## 📂 Dataset
The dataset contains World Layoffs records with missing values, duplicates, and inconsistent formats.

## 🔄 Cleaning Steps
1. Imported raw CSV data into MySQL
2. Removed duplicate records
3. Handled NULL values
4. Standardized date and text formats
5. Verified cleaned output

## 📊 Outcome
Cleaned dataset ready for analysis and visualization.
